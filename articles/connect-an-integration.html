Connect an integration

Bring your everyday tools together.

Sample article · September 5, 2026 · 1 min read

The short answer

An administrator can connect supported tools from the integrations settings. Review the permissions requested by each integration before authorizing access.

Connect the tool

  1. Open Settings → Integrations.
  2. Choose a supported integration.
  3. Select Connect.
  4. Sign in to the external tool and review the requested permissions.
  5. Authorize the connection and run a small test.

Verify the connection

Check that the integration reports a connected state, then confirm the expected action in the external tool. Start with test data that does not contain sensitive information.

Disconnect a tool

Use the integration settings to disconnect access. Review the external tool’s authorized applications as well, and remove any credentials you no longer use.

This is example content for a fictional product. Replace these steps with your product’s verified instructions before publishing.
