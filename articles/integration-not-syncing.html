An integration is not syncing

Check the connection before reconnecting.

Sample article · September 5, 2026 · 1 min read

The short answer

Check the connection status, permissions, and recent errors first. Reconnecting immediately can hide useful error details or create duplicate data.

Check the basics

  1. Confirm the integration is enabled.
  2. Check the account that authorized it still has access.
  3. Review the last successful sync and any error messages.
  4. Check the external provider’s service status.

Try a small test

Create one harmless test item and check whether it arrives. Record the time and the item identifier so support can trace it.

Ask for help

Share the integration name, the time of the last successful sync, and a redacted error message. Never include API keys or authorization tokens.

This is example content for a fictional product. Replace these steps with your product’s verified instructions before publishing.
